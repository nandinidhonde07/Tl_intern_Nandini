Introduction

This documentation covers all SolidWorks 3D modeling tasks completed during the internship session. Components modeled include the Doam Upper Part, Circular Base Plate, Rod, Part A, Part B, GT2 Pulley, Pipe/Doam Part, Curved Tray Component, and Sheet Metal Tray Design. Each part was modeled, dimensioned, annotated, and prepared as a production-ready engineering drawing.

Part 1: Doam Upper Part

Cylindrical extruded component — Ø 250 mm × 1200 mm with recess cut, fillets, and chamfers | Scale 1:20

SOLIDWORKS Sheet Metal Tray Design — Complete Workflow (All 4 Images)

What it is & where it's used: These four images together demonstrate the complete sheet metal part design workflow in SOLIDWORKS, used in manufacturing industries to create trays, enclosures, brackets, panels, and metal containers that are cut and folded from flat sheet stock.

  1. The four images collectively show the end-to-end process of designing a sheet metal tray named "Tray 2 60."
  2. Image 1 shows the Base-Flange1 feature, the foundational first step of any sheet metal part.
  3. The Base Flange takes a 2D sketch and gives it a uniform material thickness of 0.26 cm.
  4. Its Sheet Metal Parameters define gauge, bend radius, and direction (reverse/symmetric options).
  5. The tan/yellow shaded region previews the flat sheet body being created from the sketch.
  6. This step establishes the global thickness that all later features will inherit automatically.
  7. Image 2 displays the completed part in the FeatureManager Design Tree, listing all features in order.
  8. The tree shows key items: Sheet-Metal, Base-Flange1, Edge-Flange1, and a suppressed Flat-Pattern.
  9. The "Cut list" and "Flat-Pattern" features are unique to sheet metal parts for fabrication.
  10. The gray shaded body confirms the base flange (the tray's bottom floor) built successfully.
  11. Material is "not specified" and the part is still "Under Defined," needing more constraints.
  12. Image 3 shows the Edge-Flange1 feature, which folds the flat edges upward into walls.
  13. Multiple edges are selected at once to create all tray sidewalls simultaneously.
  14. The flange length is set to "Blind" at 4.00 cm, giving each wall a 4 cm height.
  15. The bend angle is 90 degrees, producing perpendicular, box-like walls.
  16. The pink/magenta arrows indicate the fold-up direction, and yellow outlines preview the geometry.
  17. Bend radius (0.07366 cm) and relief settings ensure the metal bends without cracking in reality.
  18. This step transforms the flat panel into a 3D container with depth and usable volume.
  19. Image 4 shows the Smart Dimension tool applied to the original base sketch in Top view.
  20. Dimensions like 28.01, 14.07, 13.62, and 12.71 cm define the exact tray footprint shape.
  21. The PropertyManager controls tolerance, precision (.12), dimension text, and GD&T symbols.
  22. Fully dimensioning the sketch removes the "Under Defined" status and locks the geometry.
  23. These dimensions are parametric, so changing them updates the entire 3D model instantly.
  24. Logically, the workflow flows: dimension sketch (Img 4) → base flange (Img 1) → walls (Img 3) → review (Img 2).
  25. The Sketch tab and CommandManager ribbon at the top provide all drawing and sheet metal tools.
  26. The triad in the bottom-left corner confirms part orientation in 3D modeling space.
  27. The status bar shows useful info: license type, units (CGS), and current editing state.
  28. Together these features create a manufacturable tray that can be unfolded into a flat pattern.
  29. The flat pattern is critical because it provides the cutting layout for laser/CNC machines.
  30. Overall, this set illustrates the core sheet metal principles—uniform thickness, bends, flanges, and parametric dimensioning—used in real-world fabrication and product design.
